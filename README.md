#«ПР3. Ответы на контрольные вопросы» 

1. Чем x += 5; отличается от x = x + 5;? Есть ли разница в результате? 

Разницы нет, x += 5 является более котроткой и удобной формой записи.

2. В чём разница между x++ и ++x, если результат сразу используется в выражении (например, передаётся в Console.WriteLine)? 

x++ (постфиксный инкремент): сначала возвращает старое значение переменной, а затем увеличивает её на 1.
++x (префиксный инкремент): сначала увеличивает значение переменной на 1, а затем возвращает новое значение 

3. Какой тип данных всегда получается в результате оператора сравнения (==, <, >= и т.д.)? 

Результатом любого оператора сравнения всегда является bool (логический тип). Он может принимать только два значения: true или false.

4. Что такое «короткое замыкание» в && и ||? Приведите свой пример, где это имеет практическое значение. 

Короткое замыкание - это свойство логический операторов && (И) и || (ИЛИ), при котором второй операнд не вычисляется, если резульат уже очевиден по первому операнду. Например, в A && B: если A равно false, то всё выражение уже false, поэтому B  не проверяется. В A || B: если A равно true, то всё выражение уже true, поэтому B не проверяется. Пример, шде это имеет практическое значение: проверка делителя перед делением.

5. Расставьте приоритет для выражения 10 - 2 * 3 + 4 / 2, посчитайте вручную, а затем проверьте кодом. 

1.Умножение и деление выполняются слева направо.
2.Сложение и вычитание выполняются слева направо.

Ручной рассчет:
1. 2 * 3 = 6

2. 4 / 2 = 2

3. 10 - 6 = 4 

4. 4 + 2 = 6

Результат = 6

Код: Console.WriteLine(10 - 2 * 3 + 4 / 2); // выведет 6

6. Почему хорошим тоном считается расставлять скобки даже там, где они не обязательны по приоритету операций? 

Это делается для улучшения читаемости кода. Явные скобки сразу показывают порядок вычислений и снижают риск логической ошибки, если программист неправильно помнит приоритет.
